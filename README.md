
# Автоматизация создания РПД

⚠️ **Внимание! Скрипт является экспериментальным.**

Перед массовым запуском рекомендуется проверить работу на 1–2 дисциплинах вручную.

---

## Что делает скрипт

Скрипт автоматически:

1. Создаёт РПД по списку дисциплин.
2. Копирует данные из наиболее подходящей РПД прошлых лет.
3. При необходимости назначает одного или нескольких преподавателей.
4. Утверждает созданную РПД.
5. Формирует подробный отчёт о выполнении.

Скрипт не создаёт РПД повторно, если программа уже существует. 

---

## Состав файлов

`create_from_input.py` - основной скрипт создания РПД. 

`config.py` - файл настроек.

В настройках используются параметры:
```python
LOGIN   - логин от eios
PASSWORD - пароль от eios
LOG_DIR - папка с логами
SLOW_MO - задержка перед каждым шагом в милисекундах
INPUT_FILE - имя входного csv-файла
INSTITUTE_ID - ID института, который реализует ОПОП
```

`input_disciplines.csv` - список дисциплин для обработки.

Формат:

```csv
УчебныйГод;Направление - ООП;Дисциплина;ГодНабора;Пользователь
```

Пример:

```csv
2026-2027;09.03.03 - Прикладная информатика в экономике;Информатика и кибернетика;2026;Иванов Иван Иванович
```

Для нескольких преподавателей:

```csv
2026-2027;09.03.03 - Прикладная информатика в экономике;Информатика и кибернетика;2026;Иванов Иван Иванович|Петров Петр Петрович
```

Столбец преподавателя можно оставить пустым.

## Установка

### 1. Установить Python

Рекомендуется Python 3.11+.

Проверка:

```bash
python --version
```

### 2. Установить Playwright

```bash
pip install playwright
playwright install
```

### 3. Настроить `config.py`

Указать логин и пароль ЭИОС:

```python
LOGIN = "ваш_логин"
PASSWORD = "ваш_пароль"
```

---

## Запуск

```bash
python create_from_input.py
```

Во время работы будет открываться браузер Chrome и выполняться все действия автоматически.

---

## Логи и отчёты

После завершения работы в каталоге `logs` создаются:

### Лог действий

```text
steps_from_input_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.txt
```

Содержит все действия скрипта по шагам.

### Отчёт

```text
rpd_from_input_report_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.csv
```

Содержит информацию:

* дата и время;
* дисциплина;
* направление;
* ООП;
* созданная РПД;
* источник копирования;
* преподаватели;
* статус выполнения;
* ошибки.

# Возможные проблемы

## Не найдена дисциплина

Причины:

* дисциплина отсутствует в учебном плане;
* название в CSV отличается от названия в ЭИОС.

Проверьте написание дисциплины.

---

## Не найден источник копирования

Скрипт ищет:

1. ту же дисциплину;
2. самый новый доступный учебный год;
3. самый новый доступный год набора.

Если подходящая РПД отсутствует, дисциплина будет записана в отчёт с ошибкой.

---

## Не найден преподаватель

Проверьте ФИО в столбце `Пользователь`.

Лучше использовать полное ФИО в том виде, как оно отображается в ЭИОС.

---

## Внезапно открылось окно авторизации

Обычно связано с открытым браузером Chrome, в котором уже выполнен вход в ЭИОС.

Рекомендуется:

1. Закрыть все окна Chrome.
2. Запустить скрипт повторно.

---

## Проблемы с заочной формой обучения

⚠️ Известное ограничение.

Скрипт автоматически выбирает первый доступный учебный план. Для некоторых заочных программ логика выбора может работать некорректно.

После выполнения рекомендуется дополнительно проверить результаты для заочной формы обучения вручную.

1. Форкните репозиторий (кнопка "Fork" в правом верхнем углу на GitHub).
2. Клонируйте форк к себе:
   ```bash

   cd ИМЯ_РЕПОЗИТОРИЯ
   ```
3. Создайте новую ветку:
   ```bash
   git checkout -b имя-вашей-ветки
   ```
4. Внесите изменения.

5. Зафиксируйте изменения:
   ```bash
   git add .
   git commit -m "Описание изменений"
   git push origin имя-вашей-ветки
   ```

6. Перейдите на GitHub, нажмите "Compare & pull request", выберите нужную ветку и создайте PR в `main`.
7. Напишите мне в VK/TG/Max/Email, если хотите оперативнее.

Перед отправкой:
- Проверьте, что всё работает.
- Убедитесь, что нет лишних изменений.
- Комментарии в коммитах должны быть понятными.
